# Hack Like W@CC 2026

Landing page for **Hack Like W@CC 2026 — "Back to 2016"**, the flagship annual
hackathon hosted by Women @ College of Computing at Georgia Tech.

- **Event:** October 17–18, 2026 · Georgia Tech
- **Register:** [Google Form](https://docs.google.com/forms/d/e/1FAIpQLSfbLsvdA2Yh0FmVrCgH7CV4KBoLAoM88LYy6oFgDCm-Y2LTng/viewform)

## Development

Single static `index.html` — no build step. Styling via the Tailwind CDN and
Google Fonts. Open `index.html` in a browser to preview.

## Deployment

Hosted on Vercel; pushes to `master` deploy automatically.
